## 👋 Tentang Website

Selamat datang di website portfolio pribadi saya.

Website ini dibuat sebagai media untuk memperkenalkan diri, menampilkan pengalaman, pendidikan, kemampuan, prestasi, organisasi, serta beberapa project yang pernah saya kerjakan.

Saya adalah:

**Rasya Pandu Arfiansyah**

Seorang pelajar kelas XI jurusan **Teknik Komputer dan Jaringan (TKJ)** di **SMK Negeri 1 Blitar** yang memiliki ketertarikan terhadap teknologi, jaringan komputer, bahasa, dan berbagai hal kreatif.

## ✨ Fitur Website

Website ini dibuat dengan konsep **Modern Technology + Glassmorphism** dengan perpaduan warna cyan dan hitam.

Beberapa fitur yang tersedia:

- 🌌 Particle background
- ✨ Glassmorphism UI
- 🌙 Dark mode
- ☀️ Light mode
- ⏳ Loading animation
- ⌨️ Typing animation
- 🎬 Scroll reveal animation
- 📊 Animated skill bar
- 🖱️ Custom cursor
- 🎴 3D card hover effect
- 📱 Responsive design
- 💻 Tampilan desktop
- 📱 Tampilan mobile
- 📚 Education timeline
- 🏆 Achievement section
- 👥 Organization section
- 🚀 Project showcase
- 📞 Contact section
- 💬 WhatsApp floating button
- 🎥 Project YouTube link
- 🖼️ Galeri foto
- ⚡ Interactive navigation
